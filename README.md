# Shiwang Solanki | Developer Portfolio

A personal portfolio showcasing software development projects, technical skills, education, and achievements. Built with HTML, CSS, and JavaScript, the website combines a portrait-led introduction with focused project presentations and responsive layouts.

## Overview

The portfolio highlights Shiwang Solanki’s work in backend and full-stack development, with an emphasis on Java, Spring Boot, React, REST APIs, and database-backed applications.

## Features

- Responsive layouts for desktop, tablet, and mobile screens.
- Project showcases with technology stacks, implementation highlights, and repository links.
- About section with education and academic background.
- Technical skills organized by backend, frontend, and data and delivery tools.
- Programming achievements and links to coding profiles.
- Downloadable résumé, email contact, and social links.
- Scroll-triggered reveals and subtle pointer-responsive portrait motion.
- Reduced-motion support, keyboard focus indicators, and skip navigation.

## Technology

| Layer                 | Implementation                                                |
| --------------------- | ------------------------------------------------------------- |
| Structure             | Semantic HTML5                                                |
| Styling               | CSS3, custom properties, Grid, Flexbox, and media queries     |
| Interactions          | Vanilla JavaScript, Intersection Observer, and Clipboard API  |
| Typography            | Manrope and DM Sans through Google Fonts, with fallback fonts |
| Hosting configuration | Vercel static site configuration                              |

The website runs without a frontend framework, build process, application server, or runtime API keys. Contact links open the visitor’s email application; clipboard functionality depends on browser permissions and a secure context.

## Design

An ice-blue, ivory, jade, and soft-yellow palette complements oversized headings and an editorial layout. Custom portrait artwork, a monogram, and coordinated icons establish the visual identity. The opening section uses a single face-focused portrait.
